# JavaScript DOM Manipulation

## Description

This project focuses on manipulating the DOM (Document Object Model) using JavaScript. Each task demonstrates a different DOM manipulation technique without reloading the page.

## Learning Objectives

- Select and manipulate HTML elements using JavaScript
- Update element styles and classes dynamically
- Handle user events (clicks, inputs)
- Add and remove elements from the DOM
- Fetch data from external APIs using the Fetch API

## Requirements

- All files are interpreted on Chrome browser (version 57.0 or later)
- Code must be `semistandard` compliant
- `var` is not allowed — use `const` and `let`
- The HTML page must not reload for any action

## Tasks

| File | Description |
|------|-------------|
| `0-script.js` | Updates the header text color to red using `document.querySelector` |
| `1-script.js` | Updates the header text color to red using `document.getElementById` |
| `2-script.js` | Updates the header text color when the user clicks a button |
| `3-script.js` | Toggles the class of the header between `red` and `green` on click |
| `4-script.js` | Adds a `<li>Item</li>` element to a list on click |
| `5-script.js` | Updates the header text with the value from an input field on click |
| `6-script.js` | Fetches a character name from an API and displays it |
| `7-script.js` | Fetches and lists all Star Wars movie titles from the SWAPI API |
| `8-script.js` | Fetches and displays a translation of "Hello" from an API |
